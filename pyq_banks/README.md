# Extra PYQ banks (RRB NTPC 2025-26)

Same format as `science_pyq_bank.json` (question/options in Hindi, plus `question_en` / `options_en`, `explanation`, `tip`).

- **GS (GK book, chapters History → Static GK)**: already appended to `science_pyq_bank.json` (seq 4945 onwards, `"source": "ntpc_2025_26"`), so the normal reel rotation can pick them.
- `ntpc_current_affairs.json` – Current Affairs + International (kept separate: these facts go out of date).
- `ntpc_maths.json` – Maths PYQ with short Hindi solutions.
- `ntpc_reasoning.json` – Reasoning PYQ with short Hindi solutions.

Maths / Reasoning / Current Affairs banks are not wired into any reel format yet. To use one with auto_poster: `PYQ_BANK=pyq_banks/ntpc_maths.json`.
